# Abex - فروشگاه آنلاین محصولات دیجیتال

Abex یک وب‌سایت فروشگاهی برای نمایش و خرید محصولات الکترونیکی است که با استفاده از HTML، CSS و JavaScript خالص طراحی شده است.

این پروژه با هدف تمرین و بهبود مهارت‌های توسعه فرانت‌اند، کار با API، مدیریت داده‌ها در LocalStorage و ساخت رابط کاربری یک فروشگاه اینترنتی ایجاد شده است.

## لینک پروژه

GitHub Repository:

https://github.com/shaghayeghamin/abex.git

## معرفی پروژه

در این پروژه یک فروشگاه آنلاین محصولات دیجیتال طراحی شده که کاربران می‌توانند:

- محصولات را مشاهده کنند
- محصولات را بر اساس دسته‌بندی مشاهده کنند
- محصولات را جستجو کنند
- محصولات را به سبد خرید اضافه کنند
- تعداد محصولات موجود در سبد خرید را مشاهده کنند
- محصولات مورد علاقه خود را ذخیره کنند

تمامی بخش‌های سایت به صورت Dynamic با JavaScript مدیریت شده‌اند.

## بخش‌های اصلی پروژه

### مدیریت محصولات

اطلاعات محصولات از طریق API دریافت شده و با JavaScript داخل کارت‌های محصول نمایش داده می‌شوند.

### سبد خرید

سیستم سبد خرید با استفاده از LocalStorage ساخته شده است و اطلاعات محصولات پس از Refresh شدن صفحه نیز حفظ می‌شوند.

### Wishlist

کاربران می‌توانند محصولات مورد علاقه خود را اضافه کنند(بخش حذف و نشان دادن
بعدا اضافه میشود).

### دسته‌بندی محصولات

هر دسته‌بندی صفحه مخصوص خود را دارد و محصولات مرتبط با آن نمایش داده می‌شوند.
